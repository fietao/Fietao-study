# Scores

One line per attempt, newest last. The AI appends a line after every graded check.
- **Topic** and **Format**: copied exactly from the `progress.md` checklist (`tools/status.py` flags typos).
- **Score**: got/total (e.g. 7/10). **Conf**: my confidence 1–3 BEFORE answering (1 guess · 2 unsure · 3 sure).
- **Source**: quiz (AI), mock, real (graded material).
- A box turns ✅ only after 2 passing scores (≥ 80%) in a row. Run `python tools/status.py` to check.
