# Practice

My attempts go here, one file per session: `YYYY-MM-DD-<topic>.md`.
Each attempt gets graded by a real check (run it, rubric, or compare to the source), and the score goes in `../scores.md`.
For written answers, make an anchored rubric: each point is earned only by a specific, checkable thing
(e.g. "exact quote with source"), never "rate how good it is".
